## 📌 Sobre o projeto

O **Fisioway** é um projeto web voltado à apresentação de conteúdos e materiais relacionados à fisioterapia. A aplicação reúne uma página principal e uma área específica de materiais, combinando experiência profissional em saúde com desenvolvimento de interfaces web.


## 🌐 Demonstração

[![Acessar projeto](https://img.shields.io/badge/Acessar_projeto-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://fisioway.vercel.app)

---

## ✨ Funcionalidades

- Página inicial com apresentação do projeto e navegação entre seções.
- Página dedicada à organização e disponibilização de materiais.
- Interface visual construída com HTML semântico e CSS.
- Layout adaptável para diferentes tamanhos de tela.
- Publicação contínua na Vercel.

---

## 🛠️ Tecnologias utilizadas

**HTML5**, **CSS3**, **Vercel**.

---

## 📂 Estrutura do projeto

- `index.html` — página principal do site
- `materiais.html` — página destinada aos materiais
- `style.css` — estilos, responsividade e identidade visual
- `assets/` — imagens e demais recursos visuais

---

## ▶️ Como executar

1. Clone o repositório: `git clone https://github.com/souza-jp81/fisioway.git`
2. Acesse a pasta: `cd fisioway`
3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no VS Code.

O projeto não exige instalação de dependências nem configuração de servidor para uso local.
